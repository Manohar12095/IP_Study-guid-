# CS2301 Internet Programming – Exam Study Guide

A static website with answers for the whole CS2301 question bank plus the handwritten Unit 1 to 5 list:

- **Part A (2 marks):** 32 short answers, one page per unit, tap a question to open or close its answer.
- **Part B (16 marks):** 38 full answers (theory and programs) with definitions, diagrams, tables and code.
- Programs are marked with a star (most important in the question bank).
- Each Part B answer shows the exact question bank wording it covers.

## Run locally
Double-click `index.html`. No server or install is needed.

## Features
- Sidebar with all units, search box (searches titles, keywords, question bank wording and Part A questions)
- Copy button on every code block
- Run button on HTML / CSS / JavaScript programs: shows the output right on the page
- Mark pages as completed (progress is saved in the browser)
- Dark and light mode, mobile friendly, Print / Save as PDF

## Files
- `index.html`, `style.css`, `app.js`: the site
- `helpers.js`: functions used to build answers
- `unit1.js` to `unit5.js`: first set of Part B answers
- `more1.js` to `more5.js`: question bank Part B answers (theory and programs)
- `partA.js`: all Part A (2 mark) answers
- `also.js`: links each answer to the question bank wording

## Notes
- Servlet code uses `javax.servlet`. For Tomcat 10 and later change it to `jakarta.servlet`.
- Run the AJAX program (Unit 5) through a web server such as XAMPP or `python -m http.server`.
- PHP and Servlet programs need XAMPP / Tomcat + MySQL; steps are written in each answer.
