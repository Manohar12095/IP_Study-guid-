# Internet Programming – 16 Mark Study Guide

A static website with all 18 questions (Units 1 to 5) answered as complete 16 mark answers with definitions, diagrams, tables and code.

## Run locally
Double-click `index.html` (no server or install needed).

## Features
- Sidebar with all units and questions, plus search
- Mark questions as completed (progress saved in the browser)
- Dark / light mode
- Print / Save as PDF for each answer
- Works on mobile

## Files
- `index.html`: page shell
- `style.css`: design
- `helpers.js`: helpers for building answer content
- `unit1.js` to `unit5.js`: the answers (edit these to change content)
- `app.js`: navigation, search, progress, theme
